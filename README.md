# Hub

Statische Seite für GitHub Pages. Neue Tools in `tools.js` eintragen.

## Veröffentlichen
1. Auf github.com ein neues Repository anlegen (z. B. `toolbox`, öffentlich).
2. Diese Dateien hochladen (index.html, style.css, script.js, tools.js).
3. Repository → Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. 1 Minute erreichbar unter `https://<dein-name>.github.io/toolbox/`.
